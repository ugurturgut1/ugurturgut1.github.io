# ugurturgut1.github.io

Personal site, served by GitHub Pages (Jekyll runs automatically on push).

**Add a writeup:** create `_posts/YYYY-MM-DD-slug.md` with front matter
(`title`, optional `event`, `category`), write Markdown, push. It shows up
on the home page under Writeups at `/writeups/slug/`. See `_drafts/` for a template.
